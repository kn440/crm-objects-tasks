| Проверка | Как запустить | Результат |

## Ручная проверка на рабочем сайте

Проверено 05.11.2026 на https://crm-objects-tasks-gamma.vercel.app под тремя учётными записями (см. README). Все пункты пройдены.

### Вход и доступы

- [x] Без входа любая страница перебрасывает на вход.
- [x] Неверный пароль → «Неверный email или пароль».
- [x] Постановщик видит все объекты; на объекте с задачей на проверке — жёлтая метка «На проверке».
- [x] Исполнитель 1 попадает в «Мои задачи»; объект, где у него нет задач, ему не виден.
- [x] Исполнитель 2 не видит задач исполнителя 1 внутри общих объектов.
- [x] Прямая ссылка на чужую задачу → «Задача не найдена или у вас нет к ней доступа».
- [x] Обновление страницы (F5) на внутренних страницах не даёт ошибку 404.

### Полный цикл задачи (ТЗ)

- [x] Объект без адреса и задача без исполнителя не сохраняются.
- [x] Новая задача: статус «Новая», автор — постановщик, в истории «Задача создана».
- [x] Исполнитель: «Взять в работу» → «Отправить на проверку»; после сдачи кнопок нет.
- [x] Постановщик: «Вернуть на доработку» без комментария невозможно; с комментарием — «На доработке», счётчик возвратов 1.
- [x] Исполнитель видит замечания при возврате, возвращается к работе и сдаёт снова.
- [x] Постановщик: «Принять» → «Принята», задача у исполнителя переходит в «Завершённые».
- [x] Постановщик: «Вернуть: обнаружен брак» с комментарием → «На доработке», счётчик 2.
- [x] История показывает все шаги — кто, когда, из какого статуса в какой, комментарии — одинаково обеим ролям.

### Согласованные правила

- [x] Смена исполнителя у задачи «В работе»: предупреждение, статус «Новая», запись «Исполнитель изменён: А → Б»; прежний исполнитель задачу больше не видит, новый видит.
- [x] Отмена с обязательным комментарием: статус «Отменена», кнопок нет, причина видна в карточке.
- [x] Новую задачу, которую не брали в работу, удалить можно (с подтверждением).
- [x] Задачу, которую уже брали в работу, удалить нельзя, даже если после смены исполнителя она снова «Новая».
- [x] Объект с задачами удалить нельзя; пустой объект удаляется.
- [x] Объект задачи меняется только в статусе «Новая»; у задачи в работе поле «Объект» заблокировано с подсказкой.
- [x] Название и описание меняются у задачи в работе; статус и исполнитель при этом не меняются, обновляется дата «Изменена», в историю правка не пишется (по согласованию).
- [x] У принятой задачи «Редактировать» и «Сменить исполнителя» недоступны.

### Одновременные действия

- [x] Одна задача на проверке в двух вкладках постановщика: «Принять» в первой, «Вернуть» во второй без обновления → вторая получает отказ, применено только первое решение.

### Телефон

- [x] Шапка, списки и карточки задач, окна действий корректно отображаются на ширине телефона.
